# Огни под Каневом

Одиночная изометрическая RPG. В первом техническом прототипе есть пристань, два бойца и зернохранилище, которое дружина обходит по маршруту.

## Запуск

Откройте `project.godot` в Godot 4.5.1 Standard и нажмите F5. После запуска выберите «Начать». Левой кнопкой мыши отправляйте дружину к точке на земле. Esc ставит сессию на паузу.

Проверка маршрута: `godot --headless --path . --script res://tests/run.gd`.

Проверка старта, движения двух бойцов и паузы: `godot --headless --path . --script res://tests/smoke.gd`.
