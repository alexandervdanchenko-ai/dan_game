# Проверка шейдерного кэша — 21 ноября 2026

В предыдущем замере Godot запускался с APPDATA, содержащей компонент `..`. Для диагностики сравнили открытие `user://` до и после преобразования APPDATA в канонический абсолютный путь. В короткой проверке без отрисовки первое открытие проваливалось, второе прошло. При запуске с отрисовкой и нормализованным путём Godot создал каталог шейдерного кэша, а предупреждения о каталоге исчезли. Исходник Godot 4.5.1 показывает, что GLES3 пытается открыть каталог пользовательских данных и создать в нём `shader_cache`. [Реализация GLES3](https://github.com/godotengine/godot/blob/4.5.1-stable/drivers/gles3/rasterizer_gles3.cpp#L306-L350)

## Повторный замер

Godot 4.5.1, Windows, Intel HD Graphics 520, Compatibility через ANGLE/D3D11, окно 1280×720. Три коротких прогона по 4 секунды на сцену. Первые два запуска используют один каталог профиля. Третий повторяет тест без теней.

| Профиль | Пристань: максимум | Наземный бой: p95 | Абордаж: p95 |
| --- | ---: | ---: | ---: |
| Первый запуск с новым кэшем | 3730,49 мс | 18,49 мс | 18,46 мс |
| Повторный запуск с тем же кэшем | 97,93 мс | 18,74 мс | 18,01 мс |
| Повторный запуск без теней | 320,56 мс | 18,79 мс | 18,54 мс |

Во всех трёх случаях каталог кэша был доступен к концу прогона. Повторный запуск стал заметно быстрее в этом сравнении. Первый запуск всё ещё зафиксировал задержку около 3,73 с. Тени оставляем включёнными: замер не показал устойчивого выигрыша в боевых сценах. Во всех боевых прогонах отсутствовали кадры дольше 50 мс. Целевой p95 16,7 мс пока не подтверждён. Для установления причины холодной задержки требуется отдельно замерить первый кадр пустой сцены, первый показ интерфейса и первое появление 3D с материалами.

## Как повторить

В PowerShell запустить `./tools/run-benchmark.ps1 -Godot <путь к Godot console exe> -Seconds 4 -CacheProfile trial1` дважды с одинаковым профилем. Для нового каталога выбрать ранее не использованный профиль. Для сравнения без теней добавить `-NoShadows`. Данные теста создаются под игнорируемой Git папкой `.godot`. Личные сохранения игры не используются. По умолчанию замер длится по 120 секунд на сцену.
